# IT Support Capstone: Ubuntu Innovations (Pty) Ltd

Design and implementation of an IT infrastructure and support solution for a fictional 25-person technology start-up in Cape Town, South Africa.

This is our four-week capstone project for the **Google IT Support Professional Certificate** programme, delivered through **Capaciti (a division of UVU Africa)**.

## About the project

Ubuntu Innovations (Pty) Ltd is relocating to a new office and needs a fully documented IT setup. We act as junior IT support specialists and deliver the analysis, design, security and support documentation for the whole environment.

| Department | Employees |
|---|---|
| Executive Management | 3 |
| Finance | 4 |
| Human Resources | 3 |
| Sales and Marketing | 7 |
| Software Development | 8 |
| **Total** | **25** |

**Main requirements:** secure wired and wireless connectivity, shared file storage and printers, employee accounts with department-based access control, endpoint security, backup and recovery, security policies, troubleshooting procedures, and documentation that future IT staff can use.

## Working agreements

- Add files to the correct week folder using clear names, for example `Hardware_Inventory_v2.xlsx`.
- Use a new version number instead of overwriting a file that others have reviewed.
- Write short, clear commit messages, for example `Add Week 1 hardware inventory with brand and model`.
- Use a branch and a pull request for larger changes, and ask a teammate to review before merging.
- Keep numbers consistent across documents (25 users, 20 desktops, 5 laptops, IP ranges, device names).
- Do not upload passwords, licence keys or any real personal information.
